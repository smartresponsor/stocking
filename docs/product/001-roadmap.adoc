= Stocking Roadmap

== M1

* Stock item identity.
* Stock/location levels.
* Available, reserved, and incoming quantities.

== M2

* Reservation lifecycle.
* Durable idempotency.
* Concurrency-safe availability checks.

== M3

* Append-oriented movement persistence.
* Transfers, adjustments, and reconciliation.
* Allocation extension contracts.

== M4

* Ordering/Shipping integration boundary: implemented in `../architecture/003-ordering-shipping-integration.adoc`; Stocking stays independent while composition translates sibling identities into Stocking item/location operations.
* Backorder/oversell policy and incoming projection: implemented with strict physical invariants and explicit promise policy.
* Competitor benchmark: materialized in `002-competitor-baseline.adoc`.
